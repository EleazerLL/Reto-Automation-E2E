# Reto de Automatización: Web E2E con Karate UI

Este repositorio contiene la automatización del flujo de usuario de extremo a extremo (E2E) para una plataforma de e-commerce.

## 🚀 Alcance
- **Sitio:** [SauceDemo](https://www.saucedemo.com/)
- **Flujo:** Login exitoso, filtrado de productos por precio, selección de artículos y proceso completo de checkout.
- **Herramientas:** Karate UI para la interacción con el navegador.

## 🛠️ Requisitos
- Java 17
- Maven
- Chrome instalado

## 🏃 Ejecución
Para ejecutar el flujo web:
```bash
mvn test
